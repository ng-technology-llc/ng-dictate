## Streaming Transcription

NG Dictate now includes the upstream transcribe.cpp engine work, adding support
for streaming-capable models and a live transcription overlay.

When using compatible models, text can appear while you are still speaking
instead of only after recording finishes.

## More Model Options

The Models page now includes a broader catalog of supported speech-to-text
models, including newer GGUF/transcribe.cpp model families and capability-aware
language support.

## Product Polish

- Restored the NG Dictate green accent color.
- Fixed the sidebar wordmark overlap on the settings screen.
- Added a What's New modal for bundled release notes.
- Preserved the existing remote transcription behavior while integrating the
  upstream local-model improvements.

## Before Updating

This is a large local transcription upgrade. If you rely on a specific model or
workflow, check your selected model, microphone, language, and overlay settings
after updating.
